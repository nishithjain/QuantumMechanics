|00⟩, |01⟩, |10⟩, |11⟩ as column vectors

Order is always top wire first, then bottom: |xy⟩ has digit x for qubit 1 and y for qubit 2.

KetMeaningColumn (4 entries)
|00⟩both 0(1, 0, 0, 0)ᵀ
|01⟩0 then 1(0, 1, 0, 0)ᵀ
|10⟩1 then 0(0, 0, 1, 0)ᵀ
|11⟩both 1(0, 0, 0, 1)ᵀ

Each column is |0⟩⊗|0⟩, |0⟩⊗|1⟩, |1⟩⊗|0⟩, |1⟩⊗|1⟩ from the tensor product rule in §19.
