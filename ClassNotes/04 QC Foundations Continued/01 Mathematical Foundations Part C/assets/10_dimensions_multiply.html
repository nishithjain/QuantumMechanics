Dimensions Multiply

Why an n-qubit quantum state needs 2ⁿ complex amplitudes

1. Tensor products multiply dimensions

dim(ℂm ⊗ ℂn) = m × n

A single qubit has two basis states, |0⟩ and |1⟩, so its state space is ℂ². Combining qubits means taking tensor products, so their dimensions multiply.

2. For n qubits

(ℂ²)⊗ n = ℂ2ⁿ

Each extra qubit doubles the number of computational-basis states. A general state assigns one complex amplitude to each basis state.

Number of qubits: 4

Separate qubits

2 × 4 = 8
Each qubit is described individually by two complex amplitudes: one for |0⟩ and one for |1⟩. For n separate qubits, that is 2n numbers.

Complete, general n-qubit state

2⁴ = 16
The combined system has one amplitude for every possible bit-string basis state. This general description also allows entangled states.
