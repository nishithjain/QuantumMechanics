Part 1

Complex vector spaces and basis

The problem set treats this part as prerequisite knowledge. Everything in Parts 2–4 is built directly on top of it, so it is worth being slow here. Problems 1–7 sit inside this part as checkpoints.

1The big picture

Vector spaceA collection of things you can add together and stretch by numbers, where the results always stay inside the collection.

Before working with projections, unitary matrices, or tensor products, we need to understand what a vector space actually gives us. It provides two basic operations: you can add vectors, and you can multiply vectors by scalars.

For example,

\[ v=\begin{bmatrix}1\\2\\3\end{bmatrix}, \qquad w=\begin{bmatrix}2\\0\\1\end{bmatrix} \]

can be added,

\[ v+w=\begin{bmatrix}3\\2\\4\end{bmatrix}, \]

and \(v\) can be scaled,

\[ 3v=\begin{bmatrix}3\\6\\9\end{bmatrix}. \]

What changes when the scalars are complex numbers instead of real ones?

That is where this problem set begins.

2Real vs. complex vector spaces

Complex vector spaceA vector space where the stretching numbers are allowed to be complex, so they can rotate a vector as well as resize it.

In a real vector space the scalars come from \(\mathbb R\). In a complex vector space they come from \(\mathbb C\), where a complex number has the form \(z=a+ib\) with \(i^2=-1\).

So a vector in \(\mathbb C^3\) might look like

\[ v=\begin{bmatrix}1\\2+i\\-3i\end{bmatrix}. \]

The vector itself is not necessarily complex-valued in every coordinate — its coordinates are simply allowed to be complex. That distinction becomes extremely important once we define inner products.

Yes. Complex scalars are exactly what \(\mathbb C^2\) permits.

\[ (2+i)v=\begin{bmatrix}2+i\\(2+i)i\end{bmatrix} \]

The second coordinate becomes \((2+i)i=2i+i^2=-1+2i\), so

\[ (2+i)v=\begin{bmatrix}2+i\\-1+2i\end{bmatrix}. \]

Perfectly valid.

3Linear combinations

Linear combinationWhat you get by stretching some vectors by chosen amounts and adding the results together.

What vectors can I construct from the ones I have?

The answer is described by linear combinations. Given vectors \(v_1,v_2,\ldots,v_k\), a linear combination is

\[ c_1v_1+c_2v_2+\cdots+c_kv_k, \]

where the \(c_i\) are scalars. In a complex vector space those scalars can be complex, so \(2v_1+(1+i)v_2\) is a perfectly valid linear combination of \(v_1\) and \(v_2\).

4Span

SpanEvery vector you could possibly build from a given set — the full reach of those directions.

The span of a set of vectors is the collection of every vector that can be produced by their linear combinations:

\[ \operatorname{span}\{v_1,v_2\}=\{c_1v_1+c_2v_2:c_1,c_2\in\mathbb C\}. \]

So a linear combination is one particular construction, while the span is all possible constructions.

Simple example

Let \(v_1=[1,\,0]^T\) and \(v_2=[0,\,1]^T\). Then

\[ c_1v_1+c_2v_2=\begin{bmatrix}c_1\\c_2\end{bmatrix}, \qquad\text{so}\qquad \operatorname{span}\{v_1,v_2\}=\mathbb C^2. \]

These two vectors can generate every vector in \(\mathbb C^2\).

5Linear independence

Linear independenceA set is independent when none of its vectors can be built from the others. Nothing in it is repeated information.

Are any of the vectors redundant?

A set \(\{v_1,\ldots,v_k\}\) is linearly independent if

\[ c_1v_1+\cdots+c_kv_k=0 \]

has only the trivial solution \(c_1=c_2=\cdots=c_k=0\). If a non-zero solution exists, the vectors are linearly dependent.

Intuition

Imagine three directions. If one of them can already be produced from the other two, it is redundant. For instance if \(v_3=2v_1-3v_2\), then \(2v_1-3v_2-v_3=0\) — the coefficients are not all zero, so the set is dependent.

Testing independence

Start with \(c_1v_1+c_2v_2+c_3v_3=0\), write the resulting equations coordinate by coordinate, and solve for the coefficients. Only zero coefficients possible means independent; a non-zero solution means dependent.

Problem 1Linear independence in \(\mathbb C^3\)

The problem set gives

\[ v_1=\begin{bmatrix}1\\0\\1\end{bmatrix},\quad v_2=\begin{bmatrix}0\\1\\i\end{bmatrix},\quad v_3=\begin{bmatrix}1\\i\\0\end{bmatrix} \]

and asks you to determine independence — and, if dependent, to express one vector using the other two with complex scalars.

What you should recognise. Write \(c_1v_1+c_2v_2+c_3v_3=0\) immediately, then solve the resulting complex system. Do not assume the coefficients must be real.

Seeing an \(i\) inside a vector does not mean you need a completely new method. The definition of independence is still

\[ \sum_i c_iv_i=0. \]

The only difference is that now \(c_i\in\mathbb C\).

6Basis

BasisA smallest set of directions that still reaches everywhere in the space: enough to build anything, with nothing spare.

We now have three ideas in sequence: linear combinations, then span, then independence. A basis combines the last two. A set is a basis for a vector space if it spans the space and is linearly independent.

A basis gives you enough directions to construct everything, and no unnecessary directions.

7Dimension

DimensionHow many directions a basis needs — the number of independent choices the space gives you.

The number of vectors in a basis is the dimension of the vector space. So \(\dim(\mathbb R^3)=3\), meaning any basis of \(\mathbb R^3\) contains exactly three linearly independent vectors. Similarly \(\dim(\mathbb C^2)=2\).

8Extending a set to a basis

Extending to a basisAdding new directions to a starting set until it reaches the whole space, without any of them repeating what you already have.

Suppose you are given \(v_1=[1,\,2,\,3]^T\in\mathbb R^3\) and need two more vectors. The goal is not to find special vectors. You simply need vectors that are not redundant with \(v_1\), and that together span \(\mathbb R^3\). The easiest choice is often to reach for standard basis vectors.

Problem 2Extending to a basis

Find \(v_2,v_3\) so that \(\{v_1,v_2,v_3\}\) forms a basis for \(\mathbb R^3\).

What you should recognise. You already know that basis = independent + spanning. Since three independent vectors in \(\mathbb R^3\) automatically form a basis, the practical task reduces to choosing two vectors that preserve independence.

9Coordinates with respect to a basis

CoordinatesThe amounts of each basis direction you need in order to build a given vector.

The standard basis is familiar: \(e_1=[1,\,0]^T\) and \(e_2=[0,\,1]^T\). If \(v=[3,\,2]^T\), then \(v=3e_1+2e_2\) and therefore

\[ [v]_E=\begin{bmatrix}3\\2\end{bmatrix}. \]

But the vector itself and its coordinates with respect to a basis are conceptually different things. That difference is easy to miss precisely because the standard basis makes them look identical.

10Change of basis

Change of basisRe-describing the same vector using a different set of reference directions. The vector does not move; only the numbers describing it do.

Suppose \(B=\{b_1,b_2\}\) is another basis. The same vector \(v\) can have completely different coordinates in \(B\). For the problem-set basis,

\[ b_1=\frac1{\sqrt2}\begin{bmatrix}1\\1\end{bmatrix},\qquad b_2=\frac1{\sqrt2}\begin{bmatrix}1\\-1\end{bmatrix}. \]

We want to express \(v=[1,\,0]^T\) as \(v=c_1b_1+c_2b_2\). Substituting,

\[ \begin{bmatrix}1\\0\end{bmatrix} = c_1\frac1{\sqrt2}\begin{bmatrix}1\\1\end{bmatrix} + c_2\frac1{\sqrt2}\begin{bmatrix}1\\-1\end{bmatrix}, \]

which produces two equations for \(c_1,c_2\).

Why this matters

The physical vector has not changed. Only its description has changed. Think of it as describing the same location using two different coordinate systems.

Problem 3Change of basis

Find the coordinates of \([1,\,0]^T\) in the new orthonormal basis \(B\).

Because \(B\) is orthonormal, there is an easier method that we are about to derive:

\[ \boxed{c_i=b_i^*v}. \]

This is our first hint that inner products and basis coordinates are connected.

11The complex inner product

Inner productA way of multiplying two vectors into a single number that measures how much they overlap. For complex vectors, the first one is conjugated first.

Here we reach one of the most important differences between real and complex vector spaces. For real vectors we commonly use \(u^Tv\). For complex vectors we instead use the conjugate transpose:

\[ \boxed{u^*v}. \]

Here \(u^*\) means: transpose \(u\), then complex-conjugate every entry.

Why conjugation matters

Compare \(u^Tu\) and \(u^*u\) for \(u=[1,\;ri]^T\). The conjugate transpose turns the imaginary component into a positive contribution to squared length.

12Transpose vs. conjugate transpose

Conjugate transposeTurning a column into a row and also flipping the sign of every imaginary part. Written with a star.

Take \(u=[1,\,i]^T\). The ordinary transpose is

\[ u^T=\begin{bmatrix}1&i\end{bmatrix}, \]

but the conjugate transpose is

\[ u^*=\begin{bmatrix}1&-i\end{bmatrix}, \]

because \(\overline{i}=-i\). One character of difference on paper; a completely different object in practice.

13Why can't we use \(u^Tu\)?

Squared lengthA number saying how long a vector is, squared. It must always be real, never negative, and zero only for the zero vector.

Compute it and watch it fail:

\[ u^Tu=\begin{bmatrix}1&i\end{bmatrix}\begin{bmatrix}1\\i\end{bmatrix}=1+i^2=0. \]

But \(u\neq0\). So this cannot represent a squared length. Now use the conjugate transpose instead:

\[ u^*u=\begin{bmatrix}1&-i\end{bmatrix}\begin{bmatrix}1\\i\end{bmatrix}=1+(-i)i=1+1=2, \]

and hence \(\|u\|=\sqrt2\). That is exactly what we want.

Key principle

\[ \boxed{\|u\|^2=u^*u} \]

Why? Because \(u^*u=|u_1|^2+\cdots+|u_n|^2\), which is always real and non-negative.

Quick check

For \(u=[1,\,i]^T\), which statement is true?

Problem 4Complex inner product and norms

Compare \(u^Tu\) with \(u^*u\), and explain why the second is required to define squared length in a complex vector space.

The conceptual lesson. The conjugation is not an arbitrary convention. It is what makes the squared norm behave like a genuine squared length.

14Norm

NormThe length of a vector: the square root of the sum of the squared sizes of its entries.

The norm of \(u\) is

\[ \boxed{\|u\|=\sqrt{u^*u}}. \]

For \(u=[z_1,\,z_2]^T\) we get \(\|u\|^2=|z_1|^2+|z_2|^2\). Therefore \(\|u\|\geq0\), and \(\|u\|=0\) only when \(u=0\) — the two properties any honest notion of length must have.

15Complex orthogonality

OrthogonalTwo vectors are orthogonal when their inner product is zero, meaning they share no overlap at all. It is the general version of being at right angles.

Two vectors are orthogonal if their inner product is zero:

\[ \boxed{u^*v=0}. \]

This generalises the familiar right-angle idea from real geometry.

Problem 5Complex orthogonality

Given \(x=[1,\,i]^T\) and \(y=[1,\,-i]^T\), determine whether \(x^*y=0\).

The important part is not merely calculating the product. The recognition being tested is

\[ \boxed{x\perp y\iff x^*y=0}. \]

16Orthonormality

OrthonormalA set of vectors that are all at right angles to each other and each of length exactly 1.

Two vectors are orthonormal if they are orthogonal and each have norm 1. Compactly,

\[ u_i^*u_j=\begin{cases}1&i=j\\0&i\neq j.\end{cases} \]

17Completing an orthonormal basis

Completing a basisFinding the missing directions that are perpendicular to everything you already have, then shrinking each to length 1.

Suppose you already have two orthonormal vectors in \(\mathbb C^3\):

\[ u_1=\frac1{\sqrt2}\begin{bmatrix}1\\0\\i\end{bmatrix},\qquad u_2=\begin{bmatrix}0\\1\\0\end{bmatrix}. \]

We want \(u_3\) satisfying \(u_1^*u_3=0\), \(u_2^*u_3=0\), and \(u_3^*u_3=1\). That is a system of constraints.

A useful strategy

Because \(u_2=[0,\,1,\,0]^T\), orthogonality with \(u_2\) immediately forces the second coordinate of \(u_3\) to be zero. Then use orthogonality with \(u_1\) to determine the relationship between the remaining coordinates. Finally, normalise.

Problem 6Completing an orthonormal basis

Verify that \(u_1,u_2\) are orthonormal, then construct \(u_3\) so that \(\{u_1,u_2,u_3\}\) is an orthonormal basis for \(\mathbb C^3\).

This one problem combines almost everything so far: inner product, norm, orthogonality, and basis.

18Phase factors

Phase factorA complex number whose size is exactly 1. Multiplying by it turns a vector without changing its length.

Complex numbers introduce an interesting phenomenon. Consider \(e^{i\theta}\). Euler's formula gives \(e^{i\theta}=\cos\theta+i\sin\theta\), and its magnitude is always \(|e^{i\theta}|=1\). So multiplying a vector by \(e^{i\theta}\) changes its phase but not its norm.

Indeed, \(\|e^{i\theta}v\|^2=(e^{i\theta}v)^*(e^{i\theta}v)\), and since \((e^{i\theta})^*=e^{-i\theta}\),

\[ e^{-i\theta}e^{i\theta}v^*v=v^*v, \qquad\text{hence}\qquad \boxed{\|e^{i\theta}v\|=\|v\|}. \]

Problem 7Linear combinations and phase

With \(v,w\) the standard basis vectors and

\[ x=\frac1{\sqrt2}v+\frac{e^{i\pi/4}}{\sqrt2}w, \]

prove that \(x\) is a unit vector.

The important idea. The phase factor \(e^{i\pi/4}\) has magnitude 1, so it does not change the magnitude of that component.

Part 2

Projections and orthogonal subspaces

The next question: given a vector \(v\), how much of it points in a particular direction? That is the problem of projection — and it is where a geometric idea first turns into a matrix.

19Projection onto a direction

ProjectionThe shadow one vector casts on a chosen direction — the part of it that points that way.

Suppose \(u\) is a unit vector. Given another vector \(v\), we want the component of \(v\) pointing along \(u\). The answer is

\[ \boxed{\operatorname{proj}_u(v)=u(u^*v)}. \]

Notice the order. \(u^*v\) is a scalar; then \(u(u^*v)\) is a vector.

Why this works

The inner product \(u^*v\) measures how strongly \(v\) aligns with \(u\). Multiplying by \(u\) converts that scalar amount back into a vector pointing along \(u\). So a projection is a direction multiplied by the amount along that direction.

See a projection happen

Move \(v\) and watch its projected component \(p\) and residual \(r=v-p\). The residual is perpendicular to the projection direction.

The fixed direction is \(u=(1,1)/\sqrt2\), matching Problems 8–10.

20The general projection formula

General projectionThe same shadow, corrected for the case where the direction is not already length 1, by dividing out its squared length.

If \(u\) is not normalised, then

\[ \boxed{\operatorname{proj}_u(v)=u\frac{u^*v}{u^*u}} \]

because \(u^*u=\|u\|^2\). If \(u\) is a unit vector then \(u^*u=1\) and the formula simplifies back to \(\operatorname{proj}_u(v)=u(u^*v)\).

This is worth stating explicitly every time you use the short form: it is the general formula with the assumption \(\|u\|=1\) already substituted in.

21Outer products

Outer productMultiplying a column by a row, which produces a whole matrix rather than a single number.

The expression \(uu^*\) is a matrix. It is called an outer product. If \(u\) is a unit vector, define

\[ \boxed{P=uu^*}. \]

Then \(Pv=uu^*v=u(u^*v)\), and therefore

\[ \boxed{Pv=\operatorname{proj}_u(v)}. \]

A geometric operation has become a matrix operator. Nothing new was assumed — the same expression was simply re-bracketed.

Quick check

Same two vectors, opposite order. What are \(u^*v\) and \(uv^*\)?

22Building the projection matrix

Projection matrixA single matrix that casts the shadow for you: feed it any vector and it hands back the projected part.

Problem 8Outer products as projection matrices

Given \(u=\frac1{\sqrt2}[1,\,1]^T\), compute \(P=uu^*\) and apply \(P\) to \(v=[1,\,0]^T\).

The conceptual pattern is a short pipeline:

\[ u \;\longrightarrow\; uu^* \;\longrightarrow\; P \;\longrightarrow\; Pv. \]

23Projection matrices

Applying a projectorRunning a vector through the projection matrix keeps whatever part of it lies along the chosen direction and discards the rest.

For our particular \(u=\frac1{\sqrt2}[1,\,1]^T\), the conjugate transpose is \(u^*=\frac1{\sqrt2}\begin{bmatrix}1&1\end{bmatrix}\). Therefore

\[ P=uu^*=\frac12\begin{bmatrix}1&1\\1&1\end{bmatrix}. \]

Applying \(P\) to a vector extracts its component along the direction \([1,\,1]^T\).

24Why \(P^2=P\)?

IdempotentAn operation that changes nothing further when you apply it a second time.

This property is called idempotence. Start with \(P=uu^*\) and assume \(u\) is normalised. Then

\[ P^2=(uu^*)(uu^*)=u(u^*u)u^*. \]

Because \(u^*u=1\), we get \(P^2=uu^*=P\), that is

\[ \boxed{P^2=P}. \]

Geometric meaning

Suppose you project \(v\) onto a line. After the first projection the result is already on that line, so projecting again does nothing: \(P(Pv)=Pv\), and algebraically \(P^2v=Pv\).

It is simply \(Pv\). By induction from \(P^2=P\), every power satisfies \(P^n=P\) for \(n\geq1\). Once the shadow has been cast, casting it again changes nothing — and note the tempting wrong answer, \(100\,Pv\), which would treat projection as something that accumulates.

Problem 9Properties of projectors (idempotence)

Show that \(P^2=P\) for the matrix built in Problem 8, and interpret what this means when the projection is applied repeatedly.

The key interpretation. A projection has already done its job after one application.

25Orthogonal residuals

ResidualWhat is left of a vector once its shadow is removed — the part the chosen direction could not see.

Projection does not usually reconstruct the original vector. Instead it splits it in two:

\[ v=\underbrace{Pv}_{\text{projection}}+\underbrace{(v-Pv)}_{\text{residual}}. \]

Define \(\boxed{r=v-p}\). The residual represents the part of \(v\) that lies outside the projection direction, and for an orthogonal projection

\[ \boxed{u^*r=0}. \]

So the residual is perpendicular to the projected direction.

26Why is the residual orthogonal?

Orthogonal residualThe leftover always sits at right angles to the direction you projected onto, because anything pointing along it was already taken away.

Suppose \(p=u(u^*v)\), so that \(r=v-p\). Compute:

\[ u^*r=u^*\bigl(v-u(u^*v)\bigr) = u^*v-(u^*u)(u^*v). \]

For a unit vector \(u^*u=1\), and therefore \(u^*r=0\). Notice exactly where normalisation was used — it is the same step that made \(P^2=P\) work.

Problem 10Orthogonal residuals

Using the vector and projection from Problem 8, compute the residual and prove that \(u^*r=0\).

This completes the geometric story:

\[ \boxed{v=\text{parallel component}+\text{orthogonal component}} \]

Part 3

Matrix operators

We now move from one specific operation — projection — to matrices as general operators, and ask which of them preserve geometric structure.

27Matrices as linear operators

Linear operatorA matrix seen as a machine: put a vector in, get a transformed vector out.

A matrix \(A\) takes an input vector \(x\) and produces \(Ax\). So we can think of \(A:\mathbf x\mapsto A\mathbf x\) as a transformation. A matrix might rotate vectors, reflect them, stretch them, compress them, project them, or combine several of these effects.

Which matrices preserve geometric properties?

28Unitary matrices

Unitary matrixA matrix that moves vectors around without changing any lengths — a rotation or reflection of the whole space.

In real linear algebra, orthogonal matrices preserve lengths. In complex vector spaces the corresponding concept is a unitary matrix. A matrix \(U\) is unitary if

\[ \boxed{U^*U=I}, \qquad\text{equivalently}\qquad U^{-1}=U^*. \]

29Why does unitary mean norm-preserving?

Norm preservationEvery vector comes out of the transformation exactly as long as it went in.

Take any vector \(x\). The squared norm after transformation is \(\|Ux\|^2=(Ux)^*(Ux)\). Using \((Ux)^*=x^*U^*\),

\[ \|Ux\|^2=x^*U^*Ux. \]

If \(U\) is unitary then \(U^*U=I\), so

\[ \|Ux\|^2=x^*Ix=x^*x, \qquad\text{hence}\qquad \boxed{\|Ux\|=\|x\|}. \]

The algebraic condition \(U^*U=I\) therefore has a purely geometric meaning: the transformation preserves length. It is not an arbitrary definition — it is precisely the condition that makes the middle of that chain collapse.

30Unitarity in practice

Checking unitarityMultiply the matrix by its own conjugate transpose. If you get the identity, it is unitary.

Problem 11Unitary matrices and norm preservation

For \(U=\frac1{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}\), prove that \(U^*U=I\), then prove norm preservation for an arbitrary \(x=[c_1,\,c_2]^T\).

The reasoning chain being tested:

\[ U^*U=I \;\Longrightarrow\; x^*U^*Ux=x^*x \;\Longrightarrow\; \boxed{\|Ux\|=\|x\|}. \]

The word arbitrary is the signal that a general proof is wanted, not a single numerical example.

31Hermitian matrices

Hermitian matrixA matrix that is unchanged when you transpose it and flip the signs of the imaginary parts — the complex version of symmetric.

A matrix \(H\) is Hermitian if

\[ \boxed{H=H^*}. \]

This is the complex analogue of a real symmetric matrix. Take

\[ H=\begin{bmatrix}0&-i\\i&0\end{bmatrix}. \]

To calculate \(H^*\), transpose and then conjugate. The resulting matrix is again \(\begin{bmatrix}0&-i\\i&0\end{bmatrix}\), so \(H=H^*\).

32Why are Hermitian matrices important?

Real eigenvaluesThe stretching factors of the matrix turn out to be ordinary real numbers, with no imaginary part at all.

They have a remarkable property:

\[ \boxed{\text{Their eigenvalues are real.}} \]

This is extremely useful, because the eigenvalues of a general complex matrix can be complex. For Hermitian matrices the eigenvalues behave like real geometric quantities.

33Eigenvalues and eigenvectors

Eigenvector and eigenvalueAn eigenvector is a direction the matrix does not turn, only stretches. The eigenvalue is how much it stretches by.

An eigenvector \(v\neq0\) satisfies

\[ Hv=\lambda v, \]

where \(H\) is the matrix, \(v\) an eigenvector, and \(\lambda\) its eigenvalue. The transformation acts on \(v\) without changing its direction — it only scales it.

34Finding eigenvalues

Characteristic equationThe equation you solve to find the stretching factors: set the determinant of the matrix minus λ times the identity to zero.

Rewrite \(Hv=\lambda v\) as \((H-\lambda I)v=0\). For a non-zero solution to exist we need

\[ \boxed{\det(H-\lambda I)=0}, \]

the characteristic equation. For our \(H\),

\[ H-\lambda I=\begin{bmatrix}-\lambda&-i\\i&-\lambda\end{bmatrix}, \qquad \det(H-\lambda I)=\lambda^2-1. \]

Therefore \(\lambda^2=1\), giving \(\boxed{\lambda=\pm1}\). Both eigenvalues are real.

The off-diagonal contribution to the determinant is \(-(-i)(i)\), and \((-i)(i)=-i^2=+1\). Getting this wrong turns the characteristic polynomial into \(\lambda^2+1\) and hands you imaginary eigenvalues — which should immediately alarm you, since the Hermitian check has already ruled that out.

Problem 12Hermitian matrices and real eigenvalues

Verify that the given \(H\) is Hermitian and calculate its eigenvalues, saying whether they are real or complex.

The conceptual connection to state explicitly:

\[ H=H^* \;\Longrightarrow\; \text{Hermitian} \;\Longrightarrow\; \text{real eigenvalues}. \]

35Orthogonality of eigenvectors

Orthogonal eigenvectorsFor a Hermitian matrix, directions with different stretching factors automatically sit at right angles to each other.

Another powerful property: eigenvectors corresponding to distinct eigenvalues are orthogonal. Suppose \(Hv_1=\lambda_1v_1\) and \(Hv_2=\lambda_2v_2\) with \(\lambda_1\neq\lambda_2\). Then

\[ v_1^*v_2=0. \]

This means the eigenvectors hand us natural orthogonal directions. We can normalise them so that \(v_i^*v_i=1\), and then they form an orthonormal eigenbasis — with no extra work required.

36Spectral decomposition

Spectral decompositionRebuilding a matrix as a list of its natural directions, each weighted by how much it stretches along that direction.

Once we have normalised eigenvectors, a Hermitian matrix can be reconstructed from them:

\[ \boxed{H=\sum_i\lambda_i v_iv_i^*}. \]

For two eigenvalues this reads

\[ \boxed{H=\lambda_1v_1v_1^*+\lambda_2v_2v_2^*}. \]

Why this is powerful

Instead of thinking of \(H\) as a collection of four matrix entries, we can understand it as an instruction: scale this direction by \(\lambda_1\), scale that direction by \(\lambda_2\). The eigenvectors reveal the natural directions of the transformation.

It is exactly the projection matrix from Part 2, built from a unit vector. So spectral decomposition invents nothing new: it reuses the projector once per eigendirection and weights each one by its eigenvalue. This is also why normalisation is not optional — without \(v_i^*v_i=1\), every term is scaled wrongly and the sum will not reproduce \(H\).

37Reconstructing \(H\) from its eigendirections

ReconstructionAdding those weighted pieces back together and checking that you recover the original matrix exactly.

Problem 13Eigenvectors and spectral decomposition

Find the normalised eigenvectors, verify that they are mutually orthogonal, then compute \(\lambda_1v_1v_1^*+\lambda_2v_2v_2^*\) and verify that it reconstructs \(H\).

This problem chains together five ideas at once: Hermitian → eigenvalues → eigenvectors → orthogonality → spectral decomposition.

38Matrix commutators

CommutatorA measure of whether the order of two operations matters. It comes out zero exactly when the order makes no difference.

Given two matrices \(A\) and \(B\), their commutator is

\[ \boxed{[A,B]=AB-BA}. \]

If \([A,B]=0\) then \(AB=BA\) and we say the matrices commute. If \([A,B]\neq0\), they do not.

Why order matters

For ordinary numbers \(ab=ba\). For matrices this is generally false: \(AB\) may produce a completely different result from \(BA\). This is one of the fundamental differences between scalar arithmetic and matrix algebra.

39Testing whether two operators commute

Commuting matricesTwo matrices commute when applying them in either order gives the same result.

Problem 14Matrix commutators

For \(X=\begin{bmatrix}0&1\\1&0\end{bmatrix}\) and \(Z=\begin{bmatrix}1&0\\0&-1\end{bmatrix}\), compute \([X,Z]=XZ-ZX\).

The key question is not what matrix do I get? It is: does the order in which these operators are applied matter?

Part 4

Tensor / Kronecker products

So far we have worked inside spaces such as \(\mathbb C^2\) and \(\mathbb C^3\). But what if we want to construct a larger space by combining two smaller ones? This is where the tensor product becomes useful.

40Why tensor products?

Tensor productA way of building one bigger space out of two smaller ones, covering every combination of a choice from each.

Suppose \(a\in\mathbb C^2\) and \(b\in\mathbb C^2\). Individually each vector has two coordinates. The tensor product \(a\otimes b\) belongs to a space of dimension \(2\times2=4\), so

\[ \boxed{\mathbb C^2\otimes\mathbb C^2\cong\mathbb C^4} \]

in terms of dimension. The important idea: tensor products combine the degrees of freedom of two spaces. Dimensions multiply rather than add, because the combined space must account for every pairing of a choice from the first space with a choice from the second.

41Vector Kronecker product

Kronecker product of vectorsStacking a full copy of the second vector, scaled by each entry of the first in turn.

Let \(a=[a_1,\,a_2]^T\) and \(b=[b_1,\,b_2]^T\). Then \(a\otimes b\) stacks scaled copies of \(b\):

\[ a\otimes b=\begin{bmatrix}a_1b\\a_2b\end{bmatrix} = \begin{bmatrix}a_1b_1\\a_1b_2\\a_2b_1\\a_2b_2\end{bmatrix}. \]

Read the index pattern: the first index varies slowly across the outer blocks, the second varies quickly inside each block. Keeping that ordering straight is most of the battle.

42Kronecker products of basis vectors

Dimension ruleWhen two spaces are combined this way, multiply their sizes together rather than adding them.

Problem 15Computing the vector tensor product

Given \(a=[1,\,0]^T\) and \(b=[\alpha,\,\beta]^T\), the definition gives

\[ a\otimes b=\begin{bmatrix}\alpha\\\beta\\0\\0\end{bmatrix}, \qquad\text{and for } c=[0,\,1]^T,\qquad c\otimes b=\begin{bmatrix}0\\0\\\alpha\\\beta\end{bmatrix}. \]

The problem then asks for the resulting dimension when both original vectors belong to \(\mathbb C^2\). The rule:

\[ \boxed{(m\text{-dimensional})\otimes(n\text{-dimensional})\rightarrow mn\text{-dimensional}}. \]

Notice too that \(a\otimes b\) and \(c\otimes b\) occupy disjoint halves of \(\mathbb C^4\) — a preview of how the four tensor basis vectors tile the joint space.

Build a Kronecker product

Choose \(a=[a_1,a_2]^T\) and \(b=[b_1,b_2]^T\). The four coordinates of \(a\otimes b\) are all pairwise products.

43Matrix Kronecker product

Kronecker product of matricesReplacing every entry of the first matrix with that entry times a full copy of the second matrix.

The same idea works with matrices. If \(A\) is \(m\times n\) and \(B\) is \(p\times q\), then \(A\otimes B\) has dimensions \((mp)\times(nq)\). A useful way to construct it:

Replace every scalar entry of \(A\) with that scalar multiplied by the entire matrix \(B\).

44The block-matrix picture

Block matrixA large matrix read as a grid of smaller matrices instead of a grid of individual numbers.

Let \(A=\begin{bmatrix}a&b\\c&d\end{bmatrix}\). Then

\[ A\otimes B=\begin{bmatrix}aB&bB\\cB&dB\end{bmatrix}. \]

This is the block-matrix interpretation of the Kronecker product: the left factor sets the block layout, the right factor fills each block.

Predict before calculating

With \(X=\begin{bmatrix}0&1\\1&0\end{bmatrix}\), what is the block structure of \(X\otimes I\)?

45Building a \(4\times4\) operator

Block layoutThe left factor decides how the blocks are arranged; the right factor fills in what goes inside each block.

Problem 16Matrix tensor products

Given \(I=\begin{bmatrix}1&0\\0&1\end{bmatrix}\) and \(X=\begin{bmatrix}0&1\\1&0\end{bmatrix}\), compute \(M=I\otimes X\). Because

\[ I\otimes X=\begin{bmatrix}1\,X&0\,X\\0\,X&1\,X\end{bmatrix}, \]

the result is a \(4\times4\) block matrix. Write the blocks first and expand to entries afterwards — going straight to sixteen individual entries is where mistakes come from.

46Tensor-product transformations

Tensor-product operatorAn operator acting on two combined systems at once, with each factor handling its own side and leaving the other alone.

Now we can combine transformations. Suppose \(A\) acts on one space and \(B\) acts on another. Their combined transformation is represented by

\[ \boxed{A\otimes B}, \]

an operator on the combined tensor-product space. Its defining behaviour is that each factor acts on its own subsystem: \((A\otimes B)(u\otimes w)=(Au)\otimes(Bw)\).

47Coordinate interpretation

Reading it in coordinatesSaying in words which entries a matrix swaps, keeps, or mixes together, instead of just listing its numbers.

Suppose \(w=[x_1,\,x_2,\,x_3,\,x_4]^T\). When we multiply \(Mw\), the new coordinates are linear combinations of the original ones. Rather than viewing \(M\) as just a \(4\times4\) array, ask:

Which coordinates are being exchanged, preserved, or combined?

That reading is usually far more informative than the array itself.

Problem 17Tensor space transformations

Multiply \(w\) by the matrix \(M\) from Problem 16 and describe the transformation in terms of coordinates.

The goal is to translate \(Mw\) into plain language: the first output coordinate comes from…, the second comes from…, and so on. Then say it at the tensor level too — \(I\otimes X\) leaves the first subsystem alone and applies \(X\) to the second.

48Product / factorizable vectors

Product vectorA vector in the combined space that can be split back into two smaller vectors. Not every vector can.

Here is a deeper question. Suppose \(x\in\mathbb C^4\). Can every such vector be written as \(x=u\otimes w\) with \(u,w\in\mathbb C^2\)?

No. Some vectors can be represented this way; others cannot. Those that cannot are called unfactorizable or non-product vectors with respect to this \(2\times2\) decomposition.

49What would factorization mean?

FactorizingFinding two smaller vectors whose Kronecker product rebuilds the vector you started with.

Let \(u=[u_1,\,u_2]^T\) and \(w=[w_1,\,w_2]^T\). Then

\[ u\otimes w=\begin{bmatrix}u_1w_1\\u_1w_2\\u_2w_1\\u_2w_2\end{bmatrix}. \]

So if \(x=[x_1,\,x_2,\,x_3,\,x_4]^T\), factorization requires the system

\[ u_1w_1=x_1,\qquad u_1w_2=x_2,\qquad u_2w_1=x_3,\qquad u_2w_2=x_4. \]

Can these four equations be simultaneously satisfied?

50A vector that will not factor

Unfactorizable vectorOne where no pair of smaller vectors works. Its two halves are tied together and cannot be described separately.

The problem set considers

\[ x=\frac1{\sqrt2}\begin{bmatrix}1\\0\\0\\1\end{bmatrix} \]

and assumes, for contradiction, that \(x=u\otimes w\) for two-dimensional \(u,w\). The resulting equations are

\[ u_1w_1=\tfrac1{\sqrt2},\qquad u_1w_2=0,\qquad u_2w_1=0,\qquad u_2w_2=\tfrac1{\sqrt2}. \]

From \(u_1w_1\neq0\) we know \(u_1\neq0\) and \(w_1\neq0\) — a product of numbers is non-zero only when both factors are.

But \(u_1w_2=0\) with \(u_1\neq0\) then forces \(w_2=0\). Likewise \(u_2w_1=0\) with \(w_1\neq0\) forces \(u_2=0\).

Then \(u_2w_2=0\), contradicting \(u_2w_2=\tfrac1{\sqrt2}\). Therefore the assumed factorization cannot exist:

\[ \boxed{x\neq u\otimes w} \]

for any two-dimensional \(u,w\). Note what makes this a proof rather than a failed attempt: it rules out every possible \(u\) and \(w\), not just the ones you happened to try.

Problem 18Unfactorizable vectors

Write out the implied system of four equations for \(u_1,u_2,w_1,w_2\) and prove that it has no solution, so \(x\) cannot be factored.

What the proof needs. Every division by a variable must be justified by first showing that variable is non-zero. That is where the argument does its real work.

Why this matters

This is not merely a strange algebraic puzzle. Tensor products let us distinguish between states that can be separated into two independent components and states that cannot. The latter idea becomes particularly important in areas such as quantum information — though the problem set itself only asks us to establish the mathematical fact.

Where this leaves you

Every idea in these four parts was needed by the one after it. The inner product was not introduced for its own sake — it was needed to define a norm, which was needed for orthogonality, which made projection simple, which became a matrix, which reappeared inside the spectral decomposition. Tensor products then took that whole apparatus and asked what happens when two spaces are combined.

IdeaWhat to carry forward
\(u^*v\)The inner product conjugates the first argument. That conjugation is what makes \(u^*u\) real and non-negative, and therefore what makes length meaningful.
BasisSpanning plus independence. In an \(n\)-dimensional space, \(n\) independent vectors are automatically a basis.
OrthonormalOrthogonal and unit length. Coordinates then reduce to \(c_i=b_i^*v\), with no system to solve.
\(P=uu^*\)A geometric shadow written as a matrix. \(P^2=P\) and \(u^*r=0\) both follow from \(u^*u=1\).
\(U^*U=I\)Preserves length, because \(\|Ux\|^2=x^*U^*Ux=x^*x\).
\(H=H^*\)Real eigenvalues, orthogonal eigenvectors, and hence a spectral decomposition \(H=\sum_i\lambda_iv_iv_i^*\).
\([A,B]\)Zero means order is irrelevant; non-zero means these operators have incompatible natural directions.
\(u\otimes w\)Dimensions multiply. Most vectors in the combined space are not products at all.
