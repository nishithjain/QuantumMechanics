What the black box does

Uf|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

The input x stays the same. If f(x) = 1, the helper is flipped. Because X|−⟩ = −|−⟩, that flip becomes a sign on the input component.

Uf(|x⟩|−⟩) = (−1)f(x)|x⟩|−⟩

A common minus sign on the whole state is a global phase. It does not change any measurement probability. Opposite signs between the two input components can change the result after H.
