Eigenvectors: directions that a matrix does not turn

Watch what happens when we apply A = [[2, 1], [1, 2]]. The dotted gray grid stays fixed, while the blue grid transforms. The arrows change too: eigenvectors remain along their original lines, while an ordinary vector turns.

0%
Original grid (fixed, dotted) Transformed grid (animated) Original vectors (dashed) Current vectors (solid)
At 0%, the transformation is the identity matrix. Each original arrow is in exactly the same place as its moving arrow.

Vector coordinates — shown separately to prevent overlap

u — ordinary vector

Original: u = (1, 0)

Current: (1.00, 0.00)

At 100%: Au = (2, 1). Its direction changes → not an eigenvector.

v — eigenvector

Original: v = (1, 1)

Current: (1.00, 1.00)

At 100%: Av = (3, 3) = 3v. Eigenvalue λ = 3.

w — eigenvector

Original: w = (1, −1)

Current: (1.00, −1.00)

At 100%: Aw = (1, −1) = 1w. Eigenvalue λ = 1.

Mathematical note: During the animation we smoothly interpolate from the identity I to A, using M(t) = (1 − t)I + tA. At 100%, M(1) = A.
