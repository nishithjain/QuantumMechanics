# Quantum Computing Foundations — beginner study pack

Main document: [`03_QC_Foundations_Beginner_Friendly_Notes.md`](03_QC_Foundations_Beginner_Friendly_Notes.md)

This is a detailed beginner-friendly study adaptation of Professor Amit Kumar's 25 October 2026 lecture, based on the corrected recording and the supplied slide PDF. It includes formulas, clear practical explanations, visual diagrams, step-by-step examples, measurement illustrations, 18 practice questions with answers, a formula sheet, and an alignment table describing which parts are backed by the included slides.

## Use

1. Extract the complete ZIP before opening the Markdown file.
2. Open the Markdown file in Cursor, VS Code (with a math-compatible Markdown preview), Obsidian, or another Markdown reader that supports LaTeX equations.
3. Keep the `images/` directory next to the Markdown file; the notes reference images using relative paths.
4. Optional interactives live in `animations/` (open the linked `.html` files in a browser—same folder as the notes).

**Scope:** Only slides through internal slide 12/49 are present in the supplied PDF; later portions of the notes are grounded in the provided lecture, not missing slide pages. Numerical examples clearly indicated as practice examples are explanatory additions.

The `images/` folder contains individually rendered diagrams. The `animations/` folder holds browser lessons linked from the notes (basis change, linearity, geometrical transforms, determinant and invertibility, and others). The PDF slide deck and corrected recording are separate source documents and are not reproduced inside this pack.
