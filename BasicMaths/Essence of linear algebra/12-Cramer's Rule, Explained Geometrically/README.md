# Chapter 12 — Cramer’s Rule, Explained Geometrically

This folder contains beginner-friendly, lecture-sequenced notes, **9 original illustrations**, and **3 self-contained HTML interactive demonstrations**.

## Open

1. Open `notes/lecture-notes.md` in VS Code.
2. Press Ctrl+Shift+V for Markdown Preview.
3. Follow relative image and animation links in the notes. Open `.html` files in Chrome/Edge/Firefox. No internet, server or additional libraries required.

## Contents

- `notes/lecture-notes.md` — detailed lesson, formal derivations, worked examples, common errors, eight review questions, and three additional practice problems.
- `images/` — coordinate-system and determinant diagrams.
- `animations/` — signed area, the lecture Cramer's rule numerical example, and an adjustable matrix explorer.

## Source fidelity

The lecture initially illustrates a system with output `(-4,-2)` and later checks Cramer's rule with a **different** matrix `[[2,-1],[0,1]]` and output `(4,2)` yielding `(3,2)`. The notes explicitly distinguish them. Details not in the lecture were checked against on-screen figures at approximately 145 s and 625 s. Additional teaching calculations are marked separately.
