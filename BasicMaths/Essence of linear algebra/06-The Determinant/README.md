# Lecture 06 — The Determinant

## Contents

- `notes/lecture-notes.md` — detailed beginner-friendly notes following the lecture sequence.
- `images/concept-01-determinant-area-volume.png` — original educational infographic showing 2D area scaling, shear, 3D volume, and orientation.
- `animations/animation-01-area-determinant.html` — interactive 2D transformation; change matrix entries and see the determinant, area scale, and orientation.
- `animations/animation-02-volume-determinant.html` — interactive 3D parallelepiped model illustrating volume scaling and orientation.

## How to use

1. Open `notes/lecture-notes.md` in a Markdown viewer/editor.
2. Keep the folder structure intact so the image link resolves.
3. Open each HTML file directly in a modern browser. No server, internet connection, or external JavaScript library is needed.
4. Use the sliders and Play/Pause/Reset/Step controls to explore the examples.

## Scope

The notes preserve the lecturer's progression and distinguish the lecture's spoken explanation from added beginner-friendly examples. The lecture introduces the 2 × 2 formula `ad - bc`; it does not spell out the 3 × 3 calculation formula, so the notes do not silently add one.
