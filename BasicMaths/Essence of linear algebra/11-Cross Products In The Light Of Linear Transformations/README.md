## How to use

1. Open the Markdown notes in a Markdown editor or viewer.
2. Keep the folder structure intact so the infographic link resolves.
3. Open either HTML file directly in a modern browser. No server or external libraries are needed.
4. Change the vector components to see the algebraic and geometric quantities update.

## Scope

The notes follow the supplied transcript: recap of the determinant mnemonic, duality, the signed-volume transformation, the computational derivation, the geometric base-area/perpendicular-height argument, and the conclusion that the dual vector is the cross product.
