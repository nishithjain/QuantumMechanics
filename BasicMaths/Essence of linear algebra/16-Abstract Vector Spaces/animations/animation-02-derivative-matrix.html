Differentiation as matrix multiplication

Represent a polynomial by its coefficients in the basis 1, x, x², x³, ... . The derivative matrix shifts each coefficient down one power and multiplies it by the old exponent.

Polynomial coefficients

p(x) = a₀ + a₁x + a₂x² + a₃x³

Matrix action

D = [[0,1,0,0], [0,0,2,0], [0,0,0,3], [0,0,0,0]]

Why the matrix has this pattern

The derivative of xⁿ is n xⁿ⁻¹. The coefficient n moves from the xⁿ coordinate to the xⁿ⁻¹ coordinate. This is why the matrix has 1, 2, 3, ... on the diagonal just above the main diagonal.

This is a finite display of the beginning of the infinite derivative matrix. The full polynomial space allows arbitrarily high degrees.
