Transform any vector using the 3 × 3 matrix

For the lecture's 90° rotation about y, the matrix sends (x, y, z) → (z, y, −x). Change the sliders to test it.

The blue arrow is the input vector. The green arrow is the transformed vector.

Matrix used
A = [[0, 0, 1], [0, 1, 0], [-1, 0, 0]]

Multiplying row by column gives: first output coordinate = z; second = y; third = −x.
