## How to use

1. Open `notes/lecture-notes.md` in a Markdown editor or viewer.
2. Keep the folder structure intact so the image references work.
3. Open each HTML file directly in a modern browser. They use only HTML, CSS, and vanilla JavaScript; no server or external libraries are required.
4. Use the sliders and controls to change vectors, matrices, and powers.
