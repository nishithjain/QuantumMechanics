# Lecture 09 — Dot Products and Duality

## Contents

- `notes/lecture-notes.md` — detailed beginner-friendly notes following the lecture sequence.
- `images/concept-01-dot-products-duality.png` — original educational infographic.
- `animations/animation-01-dot-product-projection.html` — interactive angle/projection/dot-product explorer.
- `animations/animation-02-duality-number-line.html` — interactive 2D-to-1D linear transformation and duality demonstration.

## How to use

1. Open the Markdown notes in a Markdown editor or viewer.
2. Keep the folder structure intact so the image link resolves.
3. Open the HTML animations directly in a modern browser. No server or external libraries are needed.
4. Use sliders and buttons to change vector directions, lengths, and the linear map.

## Scope

The notes preserve the lecture's sequence: numerical dot product, geometric projection, symmetry, transformations to the number line, the unit-vector projection argument, non-unit vectors, and duality. The lecture deliberately focuses on intuition and does not attempt a formal definition of dual spaces.
