# Lecture 13 — Change of Basis

## Contents

- `notes/lecture-notes.md` — beginner-friendly notes following the supplied lecture.
- `images/concept-01-change-of-basis.png` — educational infographic.
- `animations/animation-01-coordinate-converter.html` — interactive converter between standard and Jennifer's coordinates.
- `animations/animation-02-transformation-matrix.html` — interactive demonstration of the formula A⁻¹MA.

## How to use

1. Open the Markdown notes in a Markdown editor or viewer.
2. Keep the folder structure intact so the infographic link resolves.
3. Open the HTML files directly in a modern browser. They require no server or external libraries.
4. Change the coordinates or matrix entries and observe how the results update.

## Scope

The notes follow the lecture: basis vectors, coordinate systems, conversion matrices, inverse conversion, matrix representations of transformations, and the formula A⁻¹MA. The lecture's examples use Jennifer's basis vectors (2,1) and (-1,1), and a 90-degree counterclockwise rotation.
