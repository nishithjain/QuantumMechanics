# Lecture 10 — Cross Products

## Contents

- `notes/lecture-notes.md` — beginner-friendly notes following the lecture sequence.
- `images/concept-01-cross-products.png` — original educational infographic.
- `animations/animation-01-2d-signed-area.html` — interactive 2D cross product explorer for signed area and orientation.
- `animations/animation-02-3d-cross-product.html` — interactive 3D component calculator with a projected geometric view and right-hand-rule explanation.

## How to use

1. Open the Markdown notes in a Markdown editor or viewer.
2. Keep the folder structure intact so the image link resolves.
3. Open the HTML animations directly in a modern browser. They use vanilla JavaScript and need no server or external libraries.
4. Change the vector components or angles to explore the results.

## Scope

The notes follow the supplied lecture. This lecture covers the standard 2D signed-area interpretation, determinant calculation, 3D cross-product vector, right-hand rule, and determinant mnemonic. The deeper duality explanation is explicitly deferred to the next chapter.
