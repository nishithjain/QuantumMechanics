Explore column space, rank and null space

Use the simple matrix A = [[1, k], [0, 0]]. Its outputs always lie on the x-axis (so its column space is a line). The null space contains inputs that satisfy x + ky = 0.

What you are seeing
  • Column space: all possible outputs. Here it is the x-axis.
  • Rank: dimension of that output set. Here it is 1.
  • Null space: all input vectors mapped to zero. Here it is the line x + ky = 0.
