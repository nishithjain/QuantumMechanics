# Lecture 07 — Inverse Matrices, Column Space and Null Space

## Contents

- `notes/lecture-notes.md` — detailed beginner-friendly notes in the lecturer's sequence.
- `images/concept-01-inverse-column-null.png` — original overview infographic.
- `animations/animation-01-inverse-transformation.html` — interactive forward/reverse transformation demonstration.
- `animations/animation-02-column-null-space.html` — interactive exploration of column space, rank, and null space for a simple 2D matrix.

## How to use

1. Open the Markdown notes in a Markdown editor or viewer.
2. Keep the folder structure intact so the image link resolves.
3. Open the HTML animations directly in a modern browser. They use vanilla JavaScript and do not need a server or external libraries.
4. Use the controls and sliders to change the transformation and observe what happens.

## Scope

The lecture explicitly focuses on intuition and does not teach Gaussian elimination, row echelon form, or computational procedures for finding inverse matrices, rank, column space, or null space. The notes preserve that scope and add small worked examples only to clarify the geometric ideas.
