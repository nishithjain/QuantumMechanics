# Lecture 05 — Three-Dimensional Linear Transformations

This package contains beginner-friendly notes based on the supplied lecture transcript.

## Contents

- `notes/lecture-notes.md` — detailed notes following the lecturer's teaching sequence.
- `images/concept-01-3d-y-rotation.png` — original educational diagram of the 90° rotation about the y-axis.
- `animations/animation-01-basis-vectors.html` — interactive basis-vector mapping for the lecture's rotation.
- `animations/animation-02-vector-transform.html` — interactive vector transformation showing how `(x, y, z)` maps to `(z, y, -x)`.

## How to use

1. Open `notes/lecture-notes.md` in a Markdown editor or viewer.
2. Keep the folder structure intact so the relative image link works.
3. Open either HTML file directly in a modern browser (double-click it). No internet connection, server, or external library is required.
4. Use Play, Pause, Reset, and Step controls to explore the animations.

## Scope and accuracy

The notes preserve the order and claims in the transcript. Numerical examples are added to make the lecture's matrix operations easier to follow. The rotation matrix uses the exact basis-vector mappings stated by the lecturer.
