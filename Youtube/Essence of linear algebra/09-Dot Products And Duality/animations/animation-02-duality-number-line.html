A vector defines a transformation to the number line

Choose a direction vector u. The transformation projects each input vector v onto that direction and returns a number. For unit u, that number is v · u.

What this demonstrates
  • The 1 × 2 matrix is [uₓ uᵧ].
  • Multiplying it by [x y]ᵀ gives uₓx + uᵧy, the dot product u · v.
  • If u is a unit vector, the output is the signed projection length.
  • If u is longer, the output is scaled by |u|.
